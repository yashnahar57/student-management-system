# Student Record and Academic Management System

## Project Overview
This project is a Student Record and Academic Management System developed in Python[cite: 1]. It utilizes Python's built-in data structures—Lists, Tuples, Sets, and Dictionaries—to efficiently store, organize, update, and retrieve academic information[cite: 1].

## Data Structures Used
- **Strings:** Used for student names, departments, addresses, and email IDs[cite: 1].
- **Lists:** Used for managing student records, subject lists, marks, and attendance percentages[cite: 1].
- **Tuples:** Used for storing immutable student identifiers like PRN (Permanent Registration Number), registration number, and date of birth[cite: 1].
- **Sets:** Used for predefined departments (`AIML`, `AIDS`, `CSE`, `IT`), subjects, and student clubs[cite: 1].
- **Dictionaries:** Used to represent the complete student profile, linking personal, contact, and academic details[cite: 1].

## System Features
1. Add New Student Record (with duplicate PRN validation)[cite: 1]
2. Search Student by PRN[cite: 1]
3. Update Student Information[cite: 1]
4. Delete Record[cite: 1]
5. Calculate Average Marks[cite: 1]
6. Find Highest Scorer[cite: 1]
7. List Students by Department[cite: 1]
8. Count Total Students[cite: 1]
